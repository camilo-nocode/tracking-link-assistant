advanced-store-link-assistant 🤖
A sleek, AI-powered chat interface designed for advanced store to generate monetized tracking links via the Redirect API.

Features

Brand Aligned: Strictly follows the styleguide using #001c8e, #2b6efd, and Titillium Web.

Modern UI: Clean header design with optimized spacing and a unified onboarding message.

Automated Logic: Strips URL parameters, handles URL encoding, and remembers Site-IDs across sessions.

Setup
Copy the code from index.html.

Ensure your n8n workflow is Active.

Add your deployment domain to the CORS allowed origins in the n8n Chat Trigger.

Technology
Frontend: @n8n/chat embeddable widget.

Backend: n8n AI Agent with Postgres Chat Memory.

API: advanced store Redirect API.

File: index.html
